# Projeto Avaliativo - Sistema de Gerenciamento de Tarefas

## 👥 Nome do integrante
- Juan Borba

## 💻 Tecnologias utilizadas
- **Front-end:** HTML, CSS, JavaScript
- **Back-end:** Node.js
- **Banco de dados:** MongoDB

## 📌 Descrição do projeto
O sistema tem como objetivo gerenciar tarefas e sprints de uma equipe de desenvolvimento. Conta com funcionalidades de login, cadastro, listagem de tarefas, filtro por prioridade, e controle de progresso por Sprint.

## ✅ Resumo da Equipe

Como o projeto foi realizado de forma individual, todas as funções foram implementadas por mim. O processo foi desafiador, exigindo organização das tarefas em etapas curtas e objetivas.

### 🧠 Metodologia Ágil utilizada
Utilizei o conceito de Sprints inspirado na metodologia Scrum. A divisão em ciclos curtos me permitiu acompanhar o progresso, corrigir falhas rapidamente e melhorar a entrega contínua de valor ao produto.
